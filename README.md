# EmployeeManagementAPI

.NET 8 Web API project for Employee & Transaction Management with JWT Authentication, Role-Based Authorization, Pagination, Search, and Running Balance Logic.

---

# Features

## Employee Management
- Add Employee
- Update Employee
- Delete Employee
- Get Employee By Id
- Get All Employees
- Pagination & Search

## Authentication & Authorization
- JWT Authentication
- Role Based Access
- Admin & User Roles

## Transaction Management
- Create Credit/Debit Transaction
- Get Transactions By User
- Running Balance Logic
- Net Balance API

---

# Technologies Used

- ASP.NET Core Web API
- SQL Server
- ADO.NET
- Stored Procedures
- JWT Authentication
- Swagger
